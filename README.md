## ⚡ Présentation

Ce portfolio est une application **React moderne**, réactive, accessible et sécurisée, propulsée par **Vite** et stylisée avec **Tailwind CSS**.

Elle présente l'ensemble de mes compétences, de mon parcours académique et professionnel, ainsi qu'un catalogue détaillé de plus de **19 projets concrets** en :
- 🛡️ **Cybersécurité & Pentest** : Architectures Zero Trust, audit web applicatif (OWASP ZAP), tests d'intrusion (Kali, Metasploit, Burp Suite), détection temps réel (Suricata, rsyslog), Keycloak (IAM/2FA).
- ☁️ **Infrastructure, Cloud & DevOps** : Déploiement de clusters Kubernetes (**k3s**), conteneurisation (**Docker / Docker Compose**), virtualisation (**Proxmox VE**, VMware), Homelab & SOC privé.
- 🌐 **Réseaux & Télécoms** : Refonte et segmentation réseau d'entreprise (**Cisco IOS**, VLANs, EtherChannel, FHRP, DHCPv4/v6, pare-feu pfSense).
- 💻 **Développement Full Stack & Mobile** : Applications mobiles **React Native**, APIs REST sous **FastAPI (Python)** et **Java Spring Boot**, interfaces **Angular & React**.
- 🤖 **IA, NLP & Data Science** : Résumé automatique de texte via LLMs locaux (**Ollama Hermes**, Claude API), modèles prédictifs Machine Learning (Scikit-Learn), traitement d'images satellitaires (Matlab).

## 💻 Développement Local

### Prérequis
- [Node.js](https://nodejs.org/) (version 18 ou supérieure)
- npm

### Installation & Démarrage

```bash
# Cloner le dépôt
git clone https://github.com/Eric-YOUNGOUA/Eric-YOUNGOUA.github.io.git
cd Eric-YOUNGOUA.github.io

# Installer les dépendances
npm install

# Démarrer le serveur de développement avec HMR
npm run dev
```

Ouvrez ensuite votre navigateur sur `http://localhost:5173`.

### Compilation Production

```bash
# Compiler et optimiser les assets pour GitHub Pages
npm run build

# Prévisualiser le build de production localement
npm run preview
```
